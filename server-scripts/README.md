# Скрипты для серверов

Скрипты, которые панель отправляет на серверы сама (мастер «Новый сервер», бэкап, обходы).
Их можно запускать и вручную — всё работает без панели. Везде нужен root, проверено на Ubuntu 24.04.

| Скрипт | Где запускать | Что делает |
|---|---|---|
| `vpn-exit-setup.sh` | Новый выход | AmneziaWG 3.x модулем ядра (сервер `awg0`, без Docker, случайные параметры маскировки), BBR, fail2ban. Команда `client ИМЯ` — конфиг и QR-код для устройства напрямую на выход |
| `vpn-add-exit.sh` | Каждый вход | Создаёт на выходе AWG-клиента, поднимает здесь туннель `wgN`, добавляет исходящее `AWG-ИМЯ` в 3X-UI и ставит его **в конец** цепочки резерва |
| `vpn-backup.sh` | Основной вход | Архив: база 3X-UI, сертификаты панели, конфиги AWG, sysctl, fail2ban, версии |
| `vpn-restore.sh` | Новый вход | Ставит всё из архива, а на выходах по SSH создаёт новых AWG-клиентов для этого входа |
| `vpn-pin-chain.sh` | Вход | Отдельная цепочка резерва для одного правила маршрутизации (например, Telegram DC5) |
| `vpn-remove-client.sh` | Выход | Убирает AWG-клиентов входа, который больше не нужен |
| `vpn-zapret.sh` | Вход | zapret2 для сайтов, которые вход пускает напрямую (раздел «Zapret» в панели) |
| `vpn-awg-common.sh` | рядом с остальными | Общие функции AmneziaWG — сам не запускается, его подключают `vpn-exit-setup.sh` и `vpn-restore.sh` |
| `third_party/ipregion.sh` | — | Проверка «как видят адрес» (сторонний скрипт, запускается панелью от nobody) |

Повторный запуск безопасен: что уже настроено, скрипты пропускают. Перед правкой базы 3X-UI
делается копия (`/etc/x-ui/x-ui.db.before-…`); если Xray с новым шаблоном не поднимется, база
возвращается сама. Пароли от серверов вводятся в момент запуска и нигде не сохраняются.

## Новый выход

1. На новом сервере обновить систему и перезагрузиться, положить в /root `vpn-exit-setup.sh`
   и `vpn-awg-common.sh`:
   ```
   bash /root/vpn-exit-setup.sh
   ```
2. На **каждом входе** (рядом должны лежать `vpn-add-exit.sh`, `vpn-restore.sh` и `vpn-awg-common.sh`):
   ```
   bash /root/vpn-add-exit.sh ИМЯ_ЛАТИНИЦЕЙ IP_ВЫХОДА
   ```
   Пароль root выхода спросят один раз. На шаге 3X-UI панель и VPN входа перезапустятся на 5–10 секунд.

Место в цепочке: `POSITION=first` — первым, `POSITION=after:AWG-ИМЯ` — после этого выхода,
по умолчанию — в конец (последний резерв). Замена выхода: `REPLACE=IP_СТАРОГО` — новый встаёт
на места старого во всех цепочках, туннель до старого выключается.
`--force` пересоздаёт AWG-клиента на выходе.

Выход, поставленный этим скриптом, **не виден в приложении Amnezia** — клиентов для него
выпускает команда `bash /root/vpn-exit-setup.sh client iPhone`.

## Ещё один вход из бэкапа (горячий резерв)

1. Скопировать скрипты (PowerShell на компьютере, в папке со скриптами):
   ```
   scp vpn-backup.sh root@IP_ВХОДА:/root/
   scp vpn-restore.sh vpn-awg-common.sh root@НОВЫЙ_IP:/root/
   ```
2. На основном входе: `bash /root/vpn-backup.sh`, затем перекинуть архив на новый сервер:
   ```
   scp /root/vpn-backup-*.tar.gz root@НОВЫЙ_IP:/root/
   ```
3. На новом сервере:
   ```
   bash /root/vpn-restore.sh /root/vpn-backup-<имя>.tar.gz
   ```
   Скрипт попросит пароль root каждого выхода — по одному разу. Потом запустится официальный
   установщик 3X-UI: отвечать можно как угодно, настройки всё равно заменятся настройками из бэкапа.
4. В конце скрипт покажет адрес панели и ссылку подписки нового входа. Её добавляют на
   устройствах **второй** подпиской — получается два профиля с разными адресами.

Займёт 10–15 минут. Получится тот же входящий, те же клиенты и UUID, та же цепочка резерва и правила,
а на выходах — свои AWG-клиенты `<имя входа>-wg0`, `<имя входа>-wg1`, …

**Сертификат на IP.** Если панель и подписка основного входа работают на сертификате Let's Encrypt,
выпущенном на его IP, новому адресу он не подходит. Если установщик 3X-UI предложит выпустить
сертификат для IP — соглашайтесь. Иначе: `x-ui` → управление SSL-сертификатом → сертификат для IP-адреса.

Этапы можно запускать по отдельности (архив тот же):
```
bash vpn-restore.sh архив.tar.gz --only awg              # только AWG
bash vpn-restore.sh архив.tar.gz --only awg --force-awg  # пересоздать AWG-клиентов
bash vpn-restore.sh архив.tar.gz --skip xui              # всё, кроме 3X-UI
```
Этапы: `sysctl packages awg xui fail2ban report`.

Новый вход — копия основного на момент бэкапа. Поменяли что-то потом (правила, клиенты) —
повторите это вручную или сделайте свежий бэкап и запустите `--only xui` (он целиком заменяет
базу 3X-UI нового входа).

## Безопасность

- Архив бэкапа содержит все ключи и UUID. После развёртывания удалите его с обоих серверов:
  `rm /root/vpn-backup-*.tar.gz`
- Пароли от выходов скрипты не сохраняют.
